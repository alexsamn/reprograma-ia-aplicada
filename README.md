# reprograma-ia-aplicada

Projetos do curso **Todas em Tech Futuro+: IA Aplicada** (Reprograma, 2026), uma formação prática em inteligência artificial para mulheres, com 16 semanas.

Cada pasta reúne a entrega de projeto de uma semana, com um README que explica o desafio, o que foi feito e o que aprendi.

## Competências trabalhadas

- **Prompting:** papel, contexto, tarefa, formato e restrições; iteração; prompts que separam fato, inferência e lacuna
- **Automação com IA:** fluxos no-code (Make, Gmail, Google Sheets) com LLM numa etapa específica
- **Agentes:** instruções fixas, critérios de conclusão, gatilhos e decisão final humana
- **Dados:** diagnóstico e limpeza, denominador, tamanho de amostra, distribuição, correlação × causalidade
- **Visualização:** escolha do gráfico pela pergunta, título com conclusão, eixo no zero e n de cada grupo
- **IA responsável:** auditoria de viés, LGPD, plano de risco e revisão humana
